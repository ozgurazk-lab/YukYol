# Sevkio MVP

Yük sahipleri ile uygun nakliye araçlarını eşleştiren çalışan web MVP.

## Özellikler
- Yük ilanı
- Araç ilanı
- Rota + tarih + araç tipi + kapasite eşleştirmesi
- Uyum puanı
- Teklif oluşturma ve kabul
- Taşıma durum takibi
- LocalStorage ile tarayıcıda veri saklama

## Çalıştırma
`index.html` dosyasını açın veya basit bir statik sunucuda yayınlayın.

Bu sürüm MVP'dir; gerçek üretim sürümünde backend, kullanıcı hesabı, doğrulama, harita, canlı konum, bildirim, ödeme/komisyon ve KVKK süreçleri eklenmelidir.
